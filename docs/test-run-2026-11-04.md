## Fixed in this run

- Tab went Lite → **Build** → Coder → **Plan**: OpenCode's own agents were still active, so "press Tab for
  coder" needed two presses and Build used OpenCode's long default prompt. They are now disabled in
  `ki-config/opencode.json`; Tab switches Lite ↔ Coder.
- `install-windows.ps1 -DryRun` stopped when WSL was missing instead of listing the steps.
- `docs/test-checklist.md` still said `coder · local` and did not say that the MCP tools are in `coder` only.

## Noted, not changed

- `tunnel.sh` needs `user@host`; an SSH port other than 22 works only through `~/.ssh/config`.
- Small models pick the wrong tool now and then (move instead of trash). Every such call still needs approval.
